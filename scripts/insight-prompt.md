# 專案 insight 提示詞

`insight-harvest.py` 的下一步：把它吐出來的素材包貼給任何一個 AI，換回一則專案介紹。

用法：

```bash
python3 scripts/insight-harvest.py 一鍵開大松 > pack.json
```

把下面「提示詞」整段複製到 ChatGPT／Claude／Gemini，最後貼上 `pack.json` 的內容。

採集和產生刻意分成兩步：採集要連網、要判斷可信度，只能由這支腳本做；產生只吃素材包，誰都能跑、用哪個 AI 都行。

---

## 提示詞

````
你要為台灣公民科技資料庫（civictech.tw）的一個專案寫介紹。讀者是想找專案參與、或想借鏡做法的人，他們讀完要能判斷「這是什麼、還在不在動、我能不能加入」。

下面會附上一份「素材包」（JSON）。那是這個專案**唯一**可以使用的資料。

## 鐵則（違反任何一條，整篇作廢）

1. **只寫素材包裡有的事。** 不要用你自己知道的背景知識補充，即使你很確定。素材裡沒有的，就寫「素材中沒有」。
2. **標了「⚠️」的素材一律不得引用**，連轉述都不行。它們被判定為可能不屬於這個專案。
3. **「抓不到」清單裡的東西是「拿不到」，不是「不存在」。** 不准寫「沒有官網」「沒有社群」；要寫「官網目前無法讀取（404）」這類說法。
4. **每一句事實陳述後面加來源編號**，例如〔1〕。編號對應文末的來源列表。沒有來源的句子不准出現。
5. **判斷專案還在不在動，只能根據有日期的證據**（repo 最後 push、大松發表日期、網頁上的年份），並且寫出那個日期。沒有任何日期證據時寫「無法判斷」。**網站連得上不代表專案還在運作。**
6. **不准用評價性形容詞**（重要的、創新的、成功的、完善的、廣受好評的）。只寫它做什麼、怎麼做、誰參與、到什麼時候。
7. **素材中的帳號、密碼、金鑰、token 一律不得轉錄**，即使它看起來是範例值。
8. 素材不夠時寧可短。只寫得出兩句就交兩句，**不要為了填滿格式而重複或推測。**

## 輸出格式（繁體中文，Markdown）

### 一句話
這個專案做什麼。二十五字以內。

### 它處理的問題
一到三句。誰遇到什麼困難，這個專案怎麼回應。

### 怎麼運作
一到四句。用了什麼工具、資料或方法，使用者怎麼用它。

### 還在動嗎
`活躍`／`停擺`／`無法判斷` 三選一，後面接一句證據與日期。
判準：一年內有 push 或發表 → 活躍；最後證據超過三年 → 停擺；其餘或沒證據 → 無法判斷。

### 想參與可以做什麼
只根據素材中的「需要的人力」寫，並註明那是哪一年的需求。素材沒有就寫「素材中沒有徵求人力的紀錄」。

### 資訊缺口
一到三條：這個專案的哪些事，從目前的素材看不出來？（例如：官網失效、沒有使用數據、不知道誰在維護）

### 補欄位
一個 JSON 區塊。**只填素材裡有直接證據的欄位，其餘填 null：**

```json
{
  "status": "active | dormant | unknown",
  "last_activity": "YYYY-MM-DD 或 null",
  "last_activity_source": "證據出處 或 null",
  "license": "SPDX 代碼 或 null",
  "main_language": "程式語言 或 null",
  "first_seen": "最早一次大松發表日期 YYYY-MM-DD 或 null",
  "hackathon_count": 發表次數（整數）或 null
}
```

### 來源
編號列表，每條寫出網址與素材包的「取得日期」。

---

素材包：

（貼在這裡）
````

## 為什麼是這幾條鐵則

每一條都對應 2026-09-19／09-30 試點撞到的狀況：

| 鐵則 | 擋的是什麼 |
|---|---|
| 1 只寫素材裡有的 | AI 對知名專案（例如 Cofacts）懂得比素材多，它會很自然地把「它記得的」寫進去——那些東西無法查證，日期也不明 |
| 2 ⚠️ 不得引用 | 零時空汙的 github 欄位指向個人帳號，採集器撈到一個跟空汙無關的 repo |
| 3 抓不到≠不存在 | 五個試點有四個的官網、FB 或 hackfoldr 抓不到。寫成「沒有官網」就是錯的 |
| 5 死活只看日期 | 公務人員出國考察網連得上，但頁面寫的是「2013 ©」 |
| 7 不轉錄金鑰 | 一鍵開大松的 README 範例設定檔裡有一段 Typeform API key |
| 8 寧可短 | 素材只有一種的專案佔一半（97／212），格式硬填會長出空話 |
