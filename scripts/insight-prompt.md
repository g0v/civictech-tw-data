# 專案 insight 提示詞

`insight-harvest.py` 的下一步：把它吐出來的素材包貼給任何一個 AI，換回一則專案介紹。

用法：

```bash
python3 scripts/insight-harvest.py 一鍵開大松 > pack.json
```

把下面「提示詞」整段複製到 ChatGPT／Claude／Gemini，最後貼上 `pack.json` 的內容。

採集和產生刻意分成兩步：採集要連網、要判斷可信度，只能由這支腳本做；產生只吃素材包，誰都能跑、用哪個 AI 都行。

## 這則 insight 給誰讀

同一段文字放兩個地方：專案頁（給人看）與 API 的欄位（使用者整包丟給 AI 問）。所以它要同時滿足兩件事：

- **人讀得懂**：白話，第一次接觸公民科技的人也看得懂
- **AI 不偏心**：每一則的結構、順序、長度都差不多。字數多的專案在 AI 眼中份量就重——現有的 Intro 欄位裡，字數最多的 10% 專案佔了全部文字的一半

固定四行、每行有上限、不知道就寫「不明」，是為了這兩件事。

## 提示詞

````
你要為台灣公民科技資料庫（civictech.tw）的一個專案寫一則簡短介紹。它會同時出現在專案網頁上，以及開放資料 API 裡。讀者是第一次接觸公民科技、想找專案參與或借鏡做法的人。

下面會附上一份「素材包」（JSON）。那是這個專案**唯一**可以使用的資料。

## 鐵則（違反任何一條，整則作廢）

1. **只寫素材包裡有的事。** 不要用你自己知道的背景知識補充，即使你很確定。
2. **標了「⚠️」的素材一律不得引用**，連轉述都不行。它們被判定為可能不屬於這個專案。
3. **素材裡找不到的，那一行就寫「不明」。** 不要推測，也不要寫「沒有」——「抓不到」清單裡的東西是拿不到，不是不存在。
4. **不准用評價性形容詞**（重要的、創新的、成功的、完善的、廣受好評的）。只寫它做什麼、為誰做、怎麼做、在哪裡討論。
5. **白話。** 不寫技術架構的名詞（API、資料庫軟體、程式框架），除非這個專案本身就是給開發者用的工具。
6. **素材中的帳號、密碼、金鑰、token 一律不得轉錄**，即使它看起來是範例值。
7. **每一行都不准超過字數上限。** 上限是天花板，不是目標，素材少就寫短。

## 輸出格式

只輸出下面四行，加上來源。不要標題、不要 Markdown、不要多的說明。

做什麼：（一句話，25 字以內）
給誰、解決什麼：（誰遇到什麼困難，40 字以內）
怎麼運作：（使用者實際怎麼用它，40 字以內）
討論在哪裡：（Slack 頻道、社團、定期聚會等，40 字以內；素材包的 slack channel、non-slack 欄位與網頁內提到的都算）

來源：
（每行一個網址或資料檔名，只列你實際用到的）

---

素材包：

（貼在這裡）
````

## 為什麼是這幾條鐵則

每一條都對應 2026-09-19／09-30／10-19 試點撞到的狀況：

| 鐵則 | 擋的是什麼 |
|---|---|
| 1 只寫素材裡有的 | AI 對知名專案（例如 Cofacts）懂得比素材多，它會很自然地把「它記得的」寫進去——那些東西無法查證，日期也不明。9/30 試點時，連明知鐵則的產生者都在 Cofacts 那篇多寫了一句素材沒有的話 |
| 2 ⚠️ 不得引用 | 零時空汙的 github 欄位指向個人帳號，採集器撈到一個跟空汙無關的 repo |
| 3 不明，不是沒有 | 五個試點有四個的官網、FB 或 hackfoldr 抓不到。寫成「沒有官網」就是錯的；寫成一大段「素材中沒有……」則讓介紹讀起來像稽核報告 |
| 5 白話 | 9/30 的 Cofacts 樣本在「怎麼運作」寫了 GraphQL、Elasticsearch，第一次接觸的人讀不懂 |
| 6 不轉錄金鑰 | 一鍵開大松的 README 範例設定檔裡有一段 Typeform API key |
| 7 字數上限 | 9/30 樣本最短的不到一百字、最長的好幾百字；整包丟給 AI 時，長的專案會被偏重 |
| 不寫活動狀態與日期 | 9/30 的判準把五個裡的四個判成停擺，只有一個有直接證據；零時空汙還被後來的搜尋推翻（真正的程式碼在別的帳號，最後動靜是 2021 年）。改寫「最後可見活動」之後仍然拿掉：這種資料很快就過期，寫進文字就會跟著腐敗 |
| 不列職缺，改列討論在哪裡 | 大松紀錄裡的人力徵求是 2016–2020 年的，現在不一定還需要；告訴讀者去哪裡跟人說話比較有用 |
| 來源另列、不夾在句子裡 | 〔1〕〔2〕夾在每一句後面讀起來卡，也讓有編號的專案看起來比較有分量。來源照樣要有，只是放在最後 |

## 產生之後要做的檢查

字數不能靠 AI 自律，同步時用程式逐行數字數，超過上限就退回重產。產生後仍要有人對著來源看一次——不是審核文筆，是擋掉幻覺。
